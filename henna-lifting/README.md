# 変なものリフティング（試作）

おにぎり、生卵、すいか、スマホなど「変なもの」をタップで蹴り上げ続ける、8ビット風のブラウザゲームです。外部ライブラリなし、スマホの縦画面向け。

画面の流れは「タイトル → ステージ選択 → プレイ → リザルト（称号つき）」。低い解像度で描いてから拡大して、ドット絵に見せています。

## 遊び方

- モノを直接タップすると蹴り上がる。**左側を蹴ると右へ、右側を蹴ると左へ**飛ぶ
- 地面に落としたら終わり。蹴った回数がスコア
- **10回蹴るごとにレベルが上がり（Lv6まで）**、モノごとの演出が強くなる

| ステージ | モノ | 演出 | レベルが上がると |
|---|---|---|---|
| 1 | サッカーボール | 横風。画面全体に風の筋・葉っぱが流れ、雲が動き、風の音が鳴る（WIND の矢印で向きと強さを表示） | 風が強くなる（Lv1は無風） |
| 2 | おにぎり | 蹴るたびに米粒が飛んで小さくなる | 変わらない（小さくなること自体が難しさ） |
| 3 | 生卵 | 真ん中以外を蹴るとヒビ。4本目で割れる | 「真ん中」の幅が狭くなる |
| 4 | すいか | 蹴るたびに種がこちらに飛んできて画面に張り付き、ゆっくり垂れて画面の下に溜まる（剥がれない） | 飛んでくる種が増え、垂れるのが遅くなる |
| 5 | スマホ | 着信画面がかぶさる。蹴るたびに画面にヒビ | 着信の間隔が短く、覆う範囲が広く・濃くなる |

レベルごとの数値は `src/objects.js` の `levels` にまとまっています。

効果音は Web Audio で合成しています。蹴る音・落ちた音はモノごとに、低い「ドン」（音程が下がるサイン波）とフィルターをかけたノイズを組み合わせたリアル寄りの音、メニューやレベルアップはピコピコ音です。

## 開発

```bash
cd henna-lifting
npm run dev     # http://localhost:5173 で遊べる（同じWi-Fiのスマホからは「PCのIPアドレス:5173」）
npm test        # 物理と判定のテスト
npm run build   # 公開用に 1 ファイルにまとめた dist/artifact.html を作る
```

## 構成

```
index.html             画面（メニュー、結果、音のオンオフ）
src/objects.js         モノの定義（重さ、蹴る強さ、クセ、セリフ）。新しいモノはここに足す
src/physics.js         物理と判定（描画に依存しないのでテストできる）
src/game.js            描画、操作、効果音、自己ベストの保存、シェア
src/build-artifact.js  公開用の 1 ファイル HTML を作る
```

モノの数値（`gravity`、`kickSpeed` など）を変えると難しさを調整できます。
